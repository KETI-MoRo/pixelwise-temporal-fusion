# Revisiting Scene Change Detection with Pixel-wise Temporal Fusion

**Official repository:** `pixelwise-temporal-fusion`  
**Manuscript status:** Under minor revision at *Sensors* (MDPI)  
**Code availability:** Planned release following final acceptance

## Overview

This repository accompanies the manuscript **“Revisiting Scene Change Detection with Pixel-wise Temporal Fusion.”**

The study investigates pixel-wise temporal fusion for multi-class semantic scene change detection, using the ChangeSim benchmark.

## Release status

The manuscript is currently undergoing minor revision at *Sensors* (MDPI). This repository has been established in advance to provide a stable location for the research artifacts.

**The implementation, evaluation scripts, and model checkpoints are not yet available in this repository.** We plan to release them following final acceptance of the manuscript.

The planned release will include:

- Source code for the proposed temporal fusion framework.
- Evaluation scripts and instructions corresponding to Tables 1–6.
- Model checkpoints used to generate the reported results, subject to applicable redistribution permissions.
- Environment setup and reproduction instructions.

## Dataset and dependencies
